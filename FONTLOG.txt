FONTLOG for Sixrow and Sixrow Mono
==================================

This file provides detailed information on the Sixrow font software. This
information should be distributed along with the Sixrow fonts and any
derivative works.


Basic font information
----------------------

Sixrow is a scanline display typeface. Every capital is drawn on a grid six
rows tall, and the gap between the rows is a variable axis: at 0 the strokes
are solid, and opened up each letter splits into separate horizontal lines.

There are two families, Sixrow (proportional) and Sixrow Mono. Each is a
variable font with four axes and 16 static styles (Thin to ExtraBold, upright
and italic), in TTF and WOFF2:

  wght  Weight     100 to 800   default 400   stem thickness
  wdth  Width       75 to 150   default 100   letter body and spacing
  slnt  Slant      -16 to 0     default 0     stair-step italic: rows shift, strokes stay upright
  SCAN  Scanline     0 to 30    default 10    gap between the rows, % of the row pitch

The character set has 372 code points, the whole of Google Fonts' Latin Core
set, with the accents for every European Union language written in Latin and
dozens more. Sixrow is capitals only: lowercase code points map to the
capitals, so lowercase text sets as capitals.

The reference lettering
-----------------------

The capitals A to Z, the figures 0 to 9 and . , ( ) & $ - © were traced
from six images of lettering in reference/samples/ ("X-CTRY RACING ©2024",
"BLUE TOBACCO SMOKE...", "AEROBIC / TRAIL RUNNING", "AKIHABARA" and two
others). That lettering is Matt Waite's own original design. These glyphs are
marked src=sample in the sources.

The tabular 1 (one.tf) in Sixrow, and the 1, I, M, W, hyphen and parentheses
in Sixrow Mono, are the traced forms.


How the fonts are built
-----------------------

No font editor is involved. Every glyph is a plain-text grid in sources/
(glyphs-mono.txt, glyphs-proportional.txt), one character per half-unit and
one line per row; accented capitals are a letter plus a mark
(composites.txt), and the combining marks reuse the same accent drawings
(combining.txt). sources/config.toml holds the name, metrics and axis ranges.

tools/build.py turns the grids into upright rectangles, builds eight masters
and merges them into the variable fonts with fontTools, then instances the 16
static styles of each family. Kerning in Sixrow is generated from the row
profiles of each pair of letters. The mark and mkmk features attach the
combining marks to every letter, so decomposed text sets like the
precomposed letters. The build is reproducible: the same sources give
byte-identical fonts.

    uv venv .venv --python 3.12
    uv pip install --python .venv/bin/python -r requirements.txt
    .venv/bin/python tools/build.py


Glyphs drawn by Claude
----------------------

Glyphs marked src=draft in the sources were drawn by Claude, an AI model made
by Anthropic, working under Matt Waite's direction: in the same grid, from
the traced letters' stems, rows and corners. Matt Waite approved them for
release as drawn on 2026-11-06. They are listed here by code
point. The accent marks used for the accented capitals and combining marks
are among them; the 85 accented capitals themselves are assembled by
tools/glyphs.py from a base letter and one of those marks (Đ reuses Ð).

ChangeLog
---------

2026-11-06  Sixrow 1.000 (Matt Waite, Excellent)
- First public release, named Sixrow and Sixrow Mono (until now the face
  had only a working name).
- Licence: SIL Open Font License 1.1, no Reserved Font Name.
- Name table: copyright, manufacturer, designer, vendor and designer URLs,
  licence and licence URL; version 1.000; vendor ID XLNT.
- Character set 332 -> 372 code points: Google Fonts' Latin Core is now
  complete (see the list above).
- Romanian: T with comma below (U+021A/021B) added, and U+0162/0163 now carry
  a real cedilla. The comma-below accent is redrawn as the traced comma in
  miniature, so Ș Ț and Ģ Ķ Ļ Ņ Ŗ no longer read as cedillas; the cedilla
  now hangs from the letter's centre (on Ç and Ş it moves 2 half-units left).
- Combining marks with mark and mkmk positioning.
- Vertical metrics: ascender 960, descender -240, line gap 0 in hhea, OS/2
  typo and OS/2 win (was 768 / -120 / 0, win 850 / 130), so a line is 1.2
  times the em and accents sit inside the ascender. USE_TYPO_METRICS is set.
- Smart dropout control in the prep table (gftools fix-nonhinting).

2026-10-22  Working version 0.1.0 (not released)
- 332 code points; variable and static fonts in both families.
