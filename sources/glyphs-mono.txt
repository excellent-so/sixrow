# Sixrow — master glyph drawings (monospaced family; also the base for proportional).
#
# FORMAT
#   @ name [U+XXXX ...] [key=value ...]   starts a glyph (unicode inferred from AGL name if omitted)
#   | ....####....                        a full row (top → bottom). '#' = ink, '.' = empty
#   ' ....####....                        a half row; half rows come in pairs (top half, bottom half)
#   ---                                   baseline marker; rows after it hang below the baseline
#   ~ N                                   N empty full rows (shorthand, used by marks)
#
#   Rows above the baseline are padded at the top to 6 full rows (the cap height).
#   Anything beyond 6 rows above the baseline sits in the accent row above the caps.
#   One character = one half-unit (hu). Letter body = 24 hu, stem = 4 hu, corner inset = 2 hu.
#   Status tags: src=sample (traced from the reference lettering) | src=draft (drawn by Claude to match, under
#   Matt Waite's direction). U+ codes after the name add code points (J also sets ȷ, K also sets ĸ).
#   Marks: attach=N is the column that lines up with the base letter's centre (default: middle of the ink).
